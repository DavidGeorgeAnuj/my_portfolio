Featured Projects

Rehabilitation Exoskeleton Control System

Real-time control system for a robotic rehabilitation exoskeleton, built during a research internship at IIT Goa. A Python asyncio WebSocket server on a Raspberry Pi drives a T-Motor actuator over CAN bus, with a Flutter mobile app and web dashboard for live control and telemetry. Features a stateful, server-authoritative RBAC safety framework, self-hosted operation with no internet required, and live data plots with one-touch CSV export.

Python (asyncio) WebSockets Flutter Raspberry Pi CAN Bus

PocketCluster

Collaborated on a distributed, zero-trust cloud storage system that repurposes old or unused mobile phones as encrypted storage nodes. Files are encrypted, chunked, and replicated across the cluster, with the standout feature being semantic search (RAG) over encrypted files — natural-language file search using on-device embeddings, without ever decrypting the underlying data.
